## الخطوة 0: النسخة الاحتياطية (Backup)

**أ. من لوحة Supabase:** Database ← Backups. إذا كانت الخطة Pro تجد نسخة يومية: تأكّد أن تاريخها اليوم أو أمس.
في الخطة المجانية لا توجد نسخ تلقائية قابلة للاسترجاع، فالخيار ب ضروري.

**ب. نسخة كاملة على جهازك (موصى بها دائماً):**

```bash
sudo pacman -S postgresql        # يثبّت pg_dump (مرة واحدة)
```

في Supabase: زر **Connect** ← **Session pooler** ← انسخ الرابط **بدون كلمة السر**، ثم:

```bash
pg_dump "postgresql://postgres.nstawljljfyjhgpxuwkg@<HOST>:5432/postgres" \
  -n public -n auth -n storage -F c -f ~/waselni-backup-$(date +%F).dump
pg_restore --list ~/waselni-backup-$(date +%F).dump | grep -c "TABLE DATA"
```

يطلب كلمة سر قاعدة البيانات (لا تشاركها معي). السطر الثاني يجب أن يُظهر رقماً أكبر من 0. احتفظ بالملف.
النسخة تشمل بيانات المستخدمين والحسابات والرحلات والحجوزات والرسائل ومراجع الصور (`public` و`auth` و`storage`). ملفات الصور نفسها لا تتأثّر بالـ migrations.
